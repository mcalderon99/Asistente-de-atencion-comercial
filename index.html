Asistente de Casos

Completa los datos de la llamada, selecciona el procedimiento cuando corresponda y genera el texto final listo para copiar en el caso.

⚠️ Validación obligatoria Esta herramienta es solo de apoyo. Antes de realizar una gestión, informar condiciones o ingresar un caso, siempre valida la información y el procedimiento con el apoyo de turno.

1. Identificación del ejecutivo

Este nombre se usará automáticamente en la firma “Atte.” y quedará guardado en este navegador.

2. Tipo de registro

Usa el caso guiado cuando necesites apoyo con el procedimiento. Usa caso rápido si solo necesitas completar los datos y redactar la observación manualmente.

3. Datos de la llamada

Copia los datos desde la llamada y pégalos en sus campos correspondientes.

4. Procedimiento

Primero selecciona el tipo de gestión y luego el procedimiento o caso específico. También puedes usar una ruta rápida para gestiones frecuentes.
